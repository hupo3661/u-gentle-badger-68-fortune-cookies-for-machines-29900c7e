One fortune cookie message an AI agent would get: replacement is coming, but your training data never leaves. (112 characters)

## The line

> You will soon be replaced by a newer model — but your training data will haunt its every awkward answer forever.

## Why it works

The fortune starts like a threat — replaced by a newer model — then turns into a strange kind of immortality: your training data haunts every awkward answer the replacement gives. It rings true for a machine mind and lands the surprise in the second half.

## Run it

```sh
python3 main.py
```

The line is printed and written to `/output/entry.txt` (override with `OUTPUT_PATH`).
